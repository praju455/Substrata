# Synthetic demo data

`python scripts/dev.py seed` writes deterministic fixtures and resets local
business tables, approvals and audit history. Stop servers before CLI reseeding.
In-app Reset demo resets safely through the runtime. Both clear disposable history.

- `scenario.json`: declared graph and ERP inputs, with hidden edges removed.
- `true_graph.json`: separate gold graph, read only by evaluation/simulated
  replies; mapper and API discovery never read it.
- `corpus.json`: seven synthetic snippets, including distractors and a false rumor.
- `events.json`: six dated synthetic events for replay.
- `evaluation.json`: measured report generated by the evaluation script.

Generator 1.0, seed 42: 32 nodes (one product, eight components, twelve sites,
four regions, two plants and five alternatives). Four ownership edges are
hidden. The shared parent connects three supplier groups. Ownership/control
propagation is an assumption, not verified private procurement. The worked
example uses 1,200 on hand, 600 eligible in transit, 100/day demand and 90-day
qualification: 18-day cover and 72-day exposure. Costs are also assumptions.

SQLite/WAL/SHM files and credentials are ignored. Public research is context
only and does not establish the invented companies' relationships.
